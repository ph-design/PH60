## 设计要点

### 可打印 | 超薄 | 安装简单 | 轻量化

### 兼容性
- 兼容PH60 rev1/rev2 PCB及Multi布局PCB
- 支持ANSI/ISO布局
- 适配高特半高轴体（MX针脚兼容）
- 需使用矮轴专用卫星轴（需打磨处理）

### 强度设计
- PCB承载主要结构应力
- rev2同款加厚定位板（1.5mm）
- 热熔螺母连接上下壳
- 四角加强筋设计

### 声学优化
- PH60/Multi PCB专用底面纹理
- 加厚定位板替代夹心棉
- 硅胶脚贴减震系统
- 半高轴专用声腔

### 外观特性
- 极简无螺丝外观
- 高透光打印耗材建议
- CNC加工预留余量
- 7°自然倾角

## 配件清单
- 高特矮轴（MX兼容针脚）
- CTC超薄螺旋线
- 矮轴专用卫星轴（需自行打磨）
- M2*3*3mm热熔螺母 x10
- M2*6mm螺丝 x10
- 3M硅胶脚贴套件

## 关键安装说明

### 卫星轴处理
1. 使用矮轴专用卫星轴
2. 打磨卫星轴底部至0.8mm厚度
3. 确保卫星轴钢丝完全平整
![打磨后的卫星轴](pic/stabilizer_mod.jpg)

### 组装步骤
1. 将热熔螺母嵌入上壳对应位置
2. 安装已打磨的卫星轴至PCB
3. 轴体采用无钢板直接安装方式
4. 对齐上下壳后用M2*6螺丝固定
5. 粘贴硅胶脚贴至底部凹槽

### 注意事项
- 建议使用0.1mm层高打印外壳
- 透明耗材需进行抛光处理
- 首次通电前检查轴体针脚对位
- 推荐键帽高度：XDA/DSA
