# 简介
**PH60 Revision 3** 是一个60%尺寸的机械键盘套件，包含一套为3D打印设计的外壳和 **PH60W** 三模PCB。在本次修订版中，我们以 **无线** 和 **通用** 为设计目标重构了上一版本的诸多关键设计；添加了对不同尺寸电池和磁铁的支持；减少了非打印件的使用；并大幅优化了3D打印的耗材用量和打印时间。

![PH60 Rev3 Case](Assets/ph60r3_case_0.jpg)

## 特色

+ 🎯 面向 FDM 3D 打印设计的外壳，能够在任意打印床尺寸大于 250 mm × 250 mm 的 3D 打印机上打印，无需任何支撑。
+ 🏠 家族式的磁吸快拆卡扣结构，便于快速拆卸维护键盘的任意组件。
+ ✊ 独特的 O 型圈 Gasket 定位板，无需任何填充就能提供坚实、清脆的敲击体验。
+ 📦 模块化安装设计，支持最大 50 × 50 × 100 mm 锂聚合物电池包和 10 × 5 × 5 mm 磁铁。
+ 🔒 自锁式无线接收器收纳槽，适用于绝大多数市售 2.4 GHz 接收器外壳。
+ 🛜 第三代 **PH60W** 三模 PCB，支持 USB‑C、蓝牙 5.3 和 2.4 GHz 多种连接方式。
+ 💻 搭载 [Raspberry Pi RP2040](https://www.raspberrypi.com/products/rp2040/) 微控制器。
+ 💖 支持开源 [QMK 固件](https://qmk.fm/) 和 [VIA 配置](https://www.caniusevia.com/)（通过 JSON 文件配置）。
+ ♻️ 生命周期内持续更新 ANSI、ISO、HHKB 等多种热门布局的定位板设计。
