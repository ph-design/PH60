# PH60Slim

## 设计要点

### 可打印 | 超薄 | 安装简单 | 轻量化

### 强度

使用PCB本身抗压而非外壳

和rev2一样的加厚定位板

热熔螺母连接上下壳

### 声音

完全按PH60/Multi PCB定制底面纹理

加厚定位板取代夹心棉

硅胶脚贴减震

### 外观

极度简约

高透明耗材打印

CNC ready

## 配件

高特矮轴

超薄CTC线材

薄卫星轴和键帽

# 安装

### 所需材料

M2*3*3mm热熔螺母*10

M2*6mm螺栓*10

硅胶脚贴

高特半高机械轴

高特半高钢板卫星轴

PH60/Multi PCB（可以在仓库中找到）
